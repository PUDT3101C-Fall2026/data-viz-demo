# Data Visualization Demo

Demo repository for working with data visualization. The data was downloaded from an [NYC Open Data database of bike and pedestrian counts](https://data.cityofnewyork.us/Transportation/Bicycle-and-Pedestrian-Counts/ct66-47at/about_data).

The `RawJson.json` file was the original file I downloaded, and the `script.mjs` file is a Node.js script. To run it, call:

```
node script.mjs
```
